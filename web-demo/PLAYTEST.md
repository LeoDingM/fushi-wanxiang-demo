## 手动清单

1. WASD 走动：8 方向朝向正确，走路腿在动，松键回 idle，脚下有阴影
2. 斜走松键时不会闪回正方向（0.12 s 宽限）
3. T：时间平滑跳档，背板交叉淡化、调色渐变；夜里下雨、窗光闪
4. 走到早点摊 → E → 点单面板 → E：钱 −8，饱腹 +28，王阿姨递餐
5. 大爷会挡路；骑手偶尔斜穿马路
6. 进门 → 室内：电脑 / 做饭 / 租约 / 出门照旧
7. 床 → E：白天小睡到 19:40；夜里睡到 07:00；黑场 + 分镜，醒来灯光已变
8. HUD：地点、时钟、时段、天气、体力/心情/饱腹/金钱
